4. MANUAL FINDING: POTENTIAL PAYLOAD DISCLOSURE
Original code:
print("Payload preview:", repr(packet[Raw].load[:50]))

Observation:
The original code printed up to 50 bytes of captured payload.

Potential impact:
Sensitive information could appear in terminal output if it
is present in those captured bytes. No actual sensitive-data
disclosure was demonstrated during this review.

Remediation implemented:
Replaced payload content output with payload length output:
print("Payload length:", len(packet[Raw].load), "bytes")

Also updated the no-data message to:
print("Payload length: No Raw data")

Status:
Implemented in sniffer_secure.py.
Original sniffer.py preserved for comparison.
